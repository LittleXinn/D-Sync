# DSync

**DSync** is a class management application built exclusively for **BSIT Block/Section D**. It brings the section's day-to-day needs into one place: announcements, messaging, study materials, schedules, attendance, and class funds.

Before DSync, class information was scattered across group chats, shared drives, and notebooks. DSync replaces that with a single app that every member of the section can use, with extra tools for the officers who run it.

> **Private application:** DSync is intended for Block/Section D only. Sign-in is restricted to school email accounts (`@plpasig.edu.ph`).

## Key Features

- **Announcements and polls** to keep everyone updated and to gather class decisions quickly.
- **Class chat and direct messages** with read receipts, typing indicators, and reactions.
- **Study materials** organized by subject, searchable, and saveable.
- **Shared calendar and personal to-do list** for exams, meetings, activities, and deadlines.
- **Class funds** with per-student payment status, receipts, and class-wide totals.
- **Attendance tracking** through QR code scanning, with CSV export.
- **Admin tools** for officers: moderation, reports, class master list, role management, financial reports, and activity logs.
- **Light and dark themes**, push notifications, and in-app update prompts.

## Built With

- [Flutter](https://flutter.dev/)
- [Firebase](https://firebase.google.com/) (Authentication, Cloud Firestore, Cloud Messaging)
- Google Drive, for file and image uploads
